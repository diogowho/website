## Hardware

- **Mac mini (M6, 24GB RAM, 512GB SSD, 2.5G Ethernet)**: workstation and "home server"
- **MacBook Pro (16-inch, M3 Pro, 18GB RAM, 512GB SSD)**: my daily driver
- **iPhone 15 Pro (128GB)**
- **Apple Watch (S11)**: fitness tracking, notifications and health monitoring
- **iPad Air (M2)**: note-taking, light gaming and sketching
- **Apple Pencil Pro**: paired with my iPad for handwritten notes and drawing
- **AirPods Pro (3rd gen)**: the 3rd generation fits my ears considerably better than my old 2nd gen pair
- **Magic Mouse (USB-C)**: good battery life and convenient macOS gestures
- **Magic Keyboard (USB-C, Touch ID)**
- **AOC 32G2WG8 Monitor (1080p, 240Hz, 32-inch)**

_yes, I'm an Apple sheep hehe_

## Software

### Browser & Extensions

I currently use [**Helium**](https://helium.computer/) as my browser, with:

- [**uBlock Origin**](https://github.com/gorhill/uBlock): efficient content and ad blocker
- [**ClearURLs**](https://docs.clearurls.xyz/): automatically removes tracking elements from URLs
- [**Return YouTube Dislike**](https://returnyoutubedislike.com/): brings dislike counts back to YouTube
- [**Sink It**](https://gosinkit.com/): improves the Reddit web experience
- [**SponsorBlock**](https://sponsor.ajay.app/): automatically skips sponsored segments in YouTube videos
- [**SteamDB**](https://steamdb.info/extension/): adds SteamDB information directly to Steam
- [**Stylus**](https://github.com/openstyles/stylus): userstyles manager
- [**Violentmonkey**](https://violentmonkey.github.io/): open-source userscript manager
- [**bleh**](https://github.com/katelyynn/bleh): makes Last.fm considerably nicer to use
- [**Surfingkeys**](https://github.com/brookhong/Surfingkeys): Vim-style keyboard navigation for the web

### Communication

- [**Signal**](https://signal.org): open-source, end-to-end encrypted messaging
- [**Vesktop**](https://vesktop.dev/): a customised Discord client with additional features and customisation

### Development

- [**Ghostty**](https://ghostty.org/): feature-rich terminal emulator
- [**Neovim**](https://neovim.org/) _(btw)_: my text editor of choice; highly configurable and keyboard-driven
- [**Xcode**](https://developer.apple.com/xcode): Apple's IDE for developing macOS, iOS and other Apple-platform software
- [**container**](https://github.com/apple/container): Apple's lightweight container runtime for macOS

### Productivity

- [**Things**](https://culturedcode.com/things/): task manager for keeping track of things I need to do
- [**AeroSpace**](https://github.com/nikitabobko/AeroSpace): tiling window manager for macOS
- [**Actions**](https://sindresorhus.com/actions): extends Apple Shortcuts with additional useful actions
- [**Sketch**](https://sketch.com/): design tool
- [**HazeOver**](https://hazeover.com/): dims inactive windows to keep my attention on what I'm currently working on

### Media

- [**NetNewsWire**](https://netnewswire.com/): my preferred RSS reader
- [**Apple Music**](https://www.apple.com/apple-music/): music streaming service
- [**Pixelmator Pro**](https://www.apple.com/uk/pixelmator-pro/): photo and image editing
- [**Procreate**](https://procreate.com/): drawing and illustration on iPad
- [**ScrobbleKit**](/scrobblekit): my own open-source Last.fm scrobbler for macOS and iOS

### Utilities

- [**Homebrew**](https://brew.sh): package manager for macOS
- [**Parcel**](https://parcel.app/): package and delivery tracking
- [**Klack**](https://tryklack.com/): satisfying key sounds
- [**Flighty**](https://flighty.com/): flight tracker; excellent for keeping an eye on flights, delays and travel plans

### Security & Networking

- [**LuLu**](https://objective-see.org/products/lulu.html): open-source outbound firewall for macOS
- [**Cryptomator**](https://cryptomator.org/): open-source client-side encryption for cloud and local files
- [**WireGuard**](https://www.wireguard.com/): fast, modern VPN protocol I use for private networking and connecting my machines

### Gaming

- [**PrismLauncher**](https://prismlauncher.org/): open-source Minecraft launcher for managing instances, mods and different Minecraft versions
- [**CrossOver**](https://www.codeweavers.com/crossover/): playing Windows games on macOS without a Windows installation

### (Programming) Languages

- **JavaScript**: my first programming language and still my go-to for web development
- [**TypeScript**](https://www.typescriptlang.org/): typed superset of JavaScript that I use for most JavaScript-based projects
- [**Swift**](https://www.swift.org/): Apple-platform development language
- [**Go**](https://go.dev/): my preferred language for small systems, networking and backend projects

---

I generally prefer software that does one thing well, feels native to its platform and doesn't get in the way. I also have a _slight_ tendency to overengineer things.

I use a mixture of commercial and open-source software, and I'm perfectly happy paying for something when it saves me time or makes my life noticeably nicer.
